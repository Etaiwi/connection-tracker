# Connection Tracker for Android

Personal network notebook using your own private Google Sheet. This repository contains the mobile/web interface; Windows desktop sources are maintained locally.

Open the hosted app, connect Google with the same account as Windows, and paste the existing sheet URL in settings. Do not create a second sheet on the phone. Add the hosting origin to the Google OAuth client before signing in.

Contacts and Google tokens are not stored in this repository. The app checks for updates every 30 seconds while visible.
